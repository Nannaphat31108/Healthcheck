# ดูแลอารมณ์ครู — Emotion Care for ASD Teachers (Prototype)

เว็บต้นแบบโปรแกรมส่งเสริมการกำกับอารมณ์แบบออนไลน์สำหรับครูผู้สอนเด็กที่มีภาวะออทิซึมสเปกตรัม (8 สัปดาห์)

## ลำดับการใช้งาน (ปลดล็อกทีละขั้น)
แต่ละสัปดาห์มี 4 ขั้นตอน ต้องทำตามลำดับ ข้ามไม่ได้ (ทั้งหน้าเว็บและเซิร์ฟเวอร์ตรวจสอบ):
1. กิจกรรมที่ 1 → 2. สะท้อนตนเอง ครั้งที่ 1 → 3. สะท้อนตนเอง ครั้งที่ 2 → 4. บันทึกความรู้สึกท้ายสัปดาห์ → ปลดล็อกสัปดาห์ถัดไป
ทุกกิจกรรมแบ่งเป็นขั้นตอนย่อยทีละหน้า และทุกช่องต้องตอบ ผู้ดูแลระบบ (admin) เปิดดูได้ทุกหน้าโดยไม่ติดล็อก

## ระบบ
- `server.js` — Node.js/Express + PostgreSQL: ล็อกอิน/ลงทะเบียน, บันทึกข้อมูล, หน้าแอดมิน, ดาวน์โหลด CSV (เปิดใน Excel ได้) และ JSON
- `public/` — หน้าเว็บ (ถ้าเปิดแบบ static ไม่มี backend จะทำงานโหมดออฟไลน์ เก็บข้อมูลในเบราว์เซอร์)

## Deploy บน Render
Dashboard → New → **Blueprint** → เลือก repo นี้ → กรอก `ADMIN_USERNAME`, `ADMIN_PASSWORD` (≥ 8 ตัว), `REGISTER_CODE` (รหัสที่ให้ครูใช้สมัคร; เว้นว่าง = ใครก็สมัครได้) → Apply

## รันในเครื่อง
```
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/dulae ADMIN_USERNAME=admin ADMIN_PASSWORD=changeme123 npm start
```
เปิด http://localhost:3000

- สัปดาห์ 1 · ส้มตำความรู้สึก — เลือกอารมณ์ → วัตถุดิบลอยโค้งลงครก → กด “คลุกความรู้สึก” สากตำ น้ำกระเด็น วัตถุดิบเด้ง
- สัปดาห์ 2 · ช่อดอกไม้ความรู้สึก — เลือกดอกไม้ → ก้านงอก ดอกเด้งบานในช่อ กลีบร่วง + ทุ่งหญ้าที่ดอกไม้โผล่เด้ง (แตะเพื่อปลูก)
- สัปดาห์ 3–8 · ออกแบบสมุด, ปาสี, เติมภาพ, กล่องความรู้สึก (ลากวาง), ไทม์ไลน์เหตุการณ์, เติมดาวบนท้องฟ้า
- ทุกสัปดาห์มีการเขียนสะท้อนตนเอง 2 ครั้ง, หน้าสรุปสัปดาห์, บันทึกของฉัน (ส่งออก JSON / พิมพ์) และคลังความรู้
